  - 창의적 체험활동
  - 행동특성 및 종합의견

  - 학기별 요약 표

  - 원점수
  - 과목 평균
  - 성취도
  - A비율

- 상호작용 기능

  - 위험요소 체크
  - 로컬 메모 저장

## 4. 현재 구현의 사실 기준

- 현재 파서는 `과목 / 단위 / 등급 / 학년 / 학기` 중심으로 안정 추출
- 현재 요약은 `세특 / 창체 / 행동특성` 텍스트를 기반으로 키워드와 종합 의견을 생성
- 참조 사이트의 모든 차트와 고급 지표를 1:1로 재현하려면 PDF 원문에서 다음 필드 추출이 추가로 필요
  - 원점수
  - 평균
  - 표준편차 또는 분포 근거
  - 성취도
  - 수강자 수
