# 수프리마 진단 흐름 정리

## 인트로

- 서비스명: 수프리마 플랫폼 인트로
- 설명: 8장 구성의 인트로 이미지를 순서대로 보여 주는 시작 화면
- 목적: 진단 흐름으로 들어가기 전에 서비스 구조와 분위기를 먼저 확인하는 화면

## 1단계

- 서비스명: 학생 정보 입력
- 설명: 사용자 정보를 입력하고 학생부를 등록하는 단계
- 목적: 진단에 필요한 기본 정보와 학생부 원문을 준비하는 화면

## 2단계

- 서비스명: 학생부 분석
- 설명: 학생부 상세 분석 결과를 리포트로 제공하는 단계
- 목적: 학생부 원문, 교과 추이, 핵심 키워드, 평가 피드백을 한 화면에서 연결하는 화면

## 3단계

- 서비스명: 교과 탐구/입시문항/추천 주제
- 설명: 학생부 추출 주제와 개별 주제를 바탕으로 탐구, 입시문항, 추천 문장을 제안하는 단계
- 목적: 학생부 분석 결과를 실제 탐구 주제와 입시 활용 문장으로 확장하는 화면

## 4단계

- 서비스명: 입시 위치 진단
- 설명: 학생부 성적과 전공 적합도를 기준으로 입시 위치를 진단하는 단계
- 목적: 지원 가능 대학과 전형 적합도를 최종적으로 판단하는 화면

## 요약

- 전체 흐름은 `인트로 -> 1단계 학생 정보 입력 -> 2단계 학생부 분석 -> 3단계 교과 탐구/입시문항/추천 주제 -> 4단계 입시 위치 진단` 순서로 이어진다.
- 각 단계는 서로 분리된 목적을 가지며, 단계별로 필요한 정보만 이어서 사용한다.
