# 수프리마 랩 제품기술서

## 1. 제품명

수프리마 랩

기본 표기:

```text
수프리마 랩
학생정보 · 학생부분석 · 입시위치진단
```

- 제품 이름은 `수프리마 랩`으로 통일
- 화면 단계 이름도 같은 기준으로 사용

## 2. 제품 구성

- 1단계 학생정보입력
- 2단계 학생부 분석
- 3단계 전공주제 / 세특 / 탐구
- 4단계 입시 위치 진단

## 3. 제공 기능

### 학생정보입력

- 학생 기본 정보 입력
- 학교 정보 입력
- 학생부 PDF 등록
- 분석 요약 표시

### 학생부 분석

- 학생부 원문과 분석 결과를 함께 표시
- 학기별 추이 차트
- 성취도 요약
- 비교 분석 메모
- 인쇄 / 메일 전송

### 전공주제 / 세특 / 탐구

- 기본 3개 주제 자동 제안
- 과목별 주제, 세특, 탐구 문장 표시
- 사용자가 추가 주제를 넣어 확장 가능
- 최종 결과 인쇄 / 메일 전송

### 입시 위치 진단

- 대학 3개 기준 기본 진단
- 추가 대학 입력 기능
- 결과 값:
  - 안정
  - 도전
  - 불가
- 최종 진단 인쇄 / 메일 전송

## 4. UI 기술 기준

- 공통 화면 틀 기반 4단계 구성
- 로고 / 서비스명 / 진행 단계 공통 배치
- 2줄 서비스명 중앙 정렬
- 실제 데이터 중심 카드 구성
- 단계별 결과 문구 고정

## 5. 운영 기준

- 단계명과 화면 문구를 같은 표현으로 유지
- 메일 발송은 단계별 보고서 단위로 처리
- 인쇄 기능은 각 단계 결과 화면 단위로 처리

- 3단계 기본 / 추가 주제 구조 정리 완료
