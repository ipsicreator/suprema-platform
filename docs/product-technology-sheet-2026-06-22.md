# 나의 입시멘토 상품기술서

## 1. 상품명

나의 입시멘토

부표기:

```text
탐구·세특·입시위치진단
```

- 상품 표기 시 `나의 입시멘토` 와 `탐구·세특·입시위치진단` 은 반드시 함께 사용
- 분리 표기 금지

## 2. 상품 구성

- 1단계 학생정보입력
- 2단계 학생부 분석
- 3단계 탐구활동/독서/세특
- 4단계 입시위치 진단

## 3. 핵심 기능

### 학생정보입력

- 학생 및 보호자 기본 정보 입력
- 진로/학과 정보 입력
- 학생부 PDF 업로드
- 성적 요약 반영

### 학생부 분석

- 학생부 원문과 분석값 동시 표시
- 학기별 추이 차트
- 성취도 레이더
- 비교 평가 메모
- 인쇄/메일 발송

### 탐구활동/독서/세특

- 기본 3개 주제 자동 제안
- 주제별 논문, 자료, 독서, 세특문장 표시
- 사용자 입력 기반 추가 주제 3개 확장
- 전체 결과 인쇄/메일 발송

### 입시위치 진단

- 희망대학 3개 기본 진단
- 대학 추가 기능
- 판정값 제공
  - 하향
  - 안정
  - 도전
  - 불가
- 전 단계 요약 결합 표시
- 결과 인쇄/메일 발송

## 4. UI 기술 기준

- 공통 템플릿 기반 4단계 화면
- 로고/서비스명/배지/진행바 공통 유지
- 서비스명 2줄 좌측 정렬
- 실제 데이터 중심 노출
- 단계별 결과물 중심 구성

## 5. 운영 기준

- 단계명과 단계 설명 문구는 고정 운영
- 메일 발송은 단계별 보고서 단위 운영
- 인쇄 기능은 각 단계 결과 화면 단위 운영
