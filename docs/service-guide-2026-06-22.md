# 수프리마 랩 안내문

## 1. 서비스 이름

```text
수프리마 랩
학생정보 · 학생부분석 · 입시위치진단
```

- 학생 정보를 입력한 뒤 바로 분석 결과로 이동합니다.
- 각 단계는 하나의 흐름으로 연결됩니다.
- 중간에 어려운 용어를 쓰지 않습니다.

## 2. 서비스 소개

수프리마 랩은 학생 정보, 학생부 분석, 전공 진단, 입시 위치 진단을 한 번에 이어주는 4단계 서비스입니다.

## 3. 화면 안내

### 1단계 학생정보 입력

- 학생 기본 정보와 연락처를 입력합니다.
- 학생부 PDF를 등록합니다.
- 등록 직후 분석 요약이 보입니다.

### 2단계 학생부 분석

- 학생부 상세 분석 결과를 보여줍니다.
- 학생부 원본, 요약 비교 분석, 차트를 한 화면에서 확인합니다.
- 인쇄와 메일 보내기를 지원합니다.

### 3단계 전공진단 / 입시위치

- 학생부에서 추출한 주제를 바탕으로 전공과 입시 위치를 정리합니다.
- 기본 3개 주제를 먼저 보여줍니다.
- 추가 검색으로 최대 3개까지 확장할 수 있습니다.
- 최종 결과를 인쇄하거나 메일로 보낼 수 있습니다.

### 4단계 입시 위치 진단

- 여러 대학과 전공 기준으로 진단 결과를 보여줍니다.
- 결과는 `안정 / 도전 / 불가`로 표시합니다.
- 추가 대학을 넣어 다시 확인할 수 있습니다.

## 4. 결과 확인 방식

- 단계별 결과는 각 화면에서 바로 확인합니다.
- 메일 입력창이 있으면 해당 화면에서 바로 보냅니다.
- 각 단계의 분석 결과는 개별 카드로 보여줍니다.

## 5. 주의 사항

- 서비스 이름은 현재 `수프리마 랩` 기준으로 사용합니다.
- `AI 학생부분석 생성기`, `입시위치진단` 같은 예전 표기는 쓰지 않습니다.
- 단계명과 화면 안내 문구는 같은 표현으로 맞춥니다.
