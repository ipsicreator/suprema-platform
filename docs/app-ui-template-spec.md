# 수프리마 랩 UI 템플릿 규격

## 1. 서비스명

```text
수프리마 랩
학생정보 · 학생부분석 · 입시위치진단
```

- 서비스명은 모든 화면에서 2줄로 고정
- 아래 2줄은 반드시 같은 순서로 유지
- 1단계는 `학생정보입력`
- 2단계는 `학생부 분석`
- 3단계는 `전공주제 / 세특 / 탐구`
- 4단계는 `입시 위치 진단`
- 세 단계 문구를 다른 어려운 표현으로 바꾸지 않음

## 2. 공통 틀 기준

- 상단 좌측: 수프리마 로고
- 상단 중앙: 서비스명 2줄
- 상단 우측: 현재 단계
- 각 단계는 공통 카드 레이아웃 사용
- 실제 데이터 중심으로 보여줌

## 3. 단계명과 화면 설명

### 1단계: 학생정보입력

```text
사용자정보를 입력하고 학생부 PDF를 등록합니다.
```

### 2단계: 학생부 분석

```text
학생부 상세 분석 결과를 리포트 형태로 보여줍니다.
```

### 3단계: 전공주제 / 세특 / 탐구

```text
학생부에서 추출한 주제와 추가 주제를 함께 보여줍니다.
```

### 4단계: 입시 위치 진단

```text
학생부 기반으로 대학별 진단 결과를 보여줍니다.
```

## 4. 화면별 기준

### 1단계 화면

- 입력 항목은 학생 기본 정보와 연락처, 학교 정보, PDF 등록
- PDF 분석 결과는 등록 직후 바로 표시
- 1단계에서 학생부 분석 요약이 보여야 함

### 2단계 화면

- 학생부 원문과 분석 결과를 함께 배치
- 학기별 추이와 비교 분석 표시
- 인쇄와 메일 보내기 버튼 제공

### 3단계 화면

- 기본 3개 주제를 먼저 표시
- 주제별 세특과 탐구 문장을 함께 표시
- 사용자가 추가 주제를 넣어 확장 가능

### 4단계 화면

- 기본 3개 대학의 진단 결과 표시
- 추가 대학 입력 가능
- 결과는 안정 / 도전 / 불가로 표시

## 5. 메일 / 출력 기준

- 2단계 학생부 분석 결과만 전송 가능
- 3단계 전공주제 / 세특 / 탐구 결과만 전송 가능
- 4단계 입시 위치 진단 결과만 전송 가능
- 각 단계는 개별 결과를 인쇄할 수 있어야 함

## 6. 고정 기준

- 단계명 변경 금지
- 화면 설명 문구 변경 금지
- 서비스명 2줄 표기 유지
- 버튼 이름은 간단하고 바로 이해되는 표현만 사용
- 새 기능을 넣더라도 현재 화면 흐름을 바꾸지 않음
