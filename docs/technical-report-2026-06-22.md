# 수프리마 랩 기술 보고서

작성 기준일: 2026-06-22

## 1. 개요

현재 작업 기준 서비스는 `수프리마 랩`이며, 진단 화면은 1단계부터 4단계까지 하나의 흐름으로 연결되어 있습니다.

```text
수프리마 랩
학생정보 · 학생부분석 · 입시위치진단
```

2단계는 학생부 분석 결과를 한 화면에서 보여주는 구간입니다.

이번 작업의 목적은 전체 구조를 하나의 공통 화면 틀로 맞추고, 각 단계가 실제 입력값과 결과값을 보여주도록 정리하는 것입니다.

## 2. 반영 범위

- 1단계 학생정보 입력 정리
- 2단계 학생부 분석 대시보드 구조 반영
- 3단계 과목별/주제별 분석 화면 반영
- 4단계 입시 위치 진단 결과 화면 반영
- 공통 화면 틀과 단계 표시 방식 정리
- 단계별 전환 및 메일 전송 동작 정리
- 최신 화면 캡처 생성

## 3. 구현 상태

### 3.1 공통 화면

- 좌측 로고, 중앙 서비스명 2줄, 우측 단계명 표기
- 1~4단계 공통 진행 구조
- 현재 단계 강조 처리
- 모든 단계의 동일한 레이아웃 적용

### 3.2 1단계

- 사용자 정보 입력 완료
- 학생부 PDF 업로드 구간 정리
- PDF 분석 결과의 기본 요약 표시
- 학생부 분석 미리보기 카드 표시

### 3.3 2단계

- 1단계 분석 결과 기반 학생부 원본 정보 표시
- 학생부 요약·비교 분석 표시
- 학생부 분석 결과와 연동된 차트 표시
- 메일 / 인쇄 기능 연결

### 3.4 3단계

- 기본 3주제 추천
- 주제별 학생부, 독서, 세특, 탐구 문장 구성
- 개인 주제 추가 검색으로 최대 3개 확장
- 전체 결과를 인쇄 또는 메일로 전송 가능

### 3.5 4단계

- 3단계 결과를 바탕으로 입시 위치 진단 카드 표시
- 기본 3개 대학과 선호 전공 진단 구성
- 안정 / 도전 / 불가 판정 표시
- 추가 대학 입력 기능 반영
- 인쇄 / 메일 기능 연결
